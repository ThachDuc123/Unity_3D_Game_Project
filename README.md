##  About the Project

**Unity 3D Game Project** is a 3D game-development project built with **Unity** and **C#**.

The repository contains the Unity project files, including the game assets, project configuration and source code required to continue development inside the Unity Editor.

The project is organized as a standard Unity project:

```text
Unity Project
│
├── Assets
│   └── Game content & scripts
│
├── Packages
│   └── Unity package dependencies
│
└── ProjectSettings
    └── Project configuration
```

# ⚡ Getting Started

## Requirements

Install:

* Unity Hub
* A Unity Editor version compatible with the project's `ProjectSettings`
* Visual Studio or VS Code with Unity/C# support

---

## 1. Clone the repository

```bash
git clone https://github.com/ThachDuc123/unity-3D.git

cd unity-3D
```

---

## 2. Open the project

Open **Unity Hub** and select:

```text
Add → Add project from disk
```

Choose the cloned project directory.

Unity will automatically import the project assets and packages.

---

## 3. Open a Scene

Inside the Unity Editor:

```text
Project
└── Assets
    └── Scenes
```

Open the main available scene and press:

```text
▶ Play
```

to run the project.

---

#  Development Workflow

The project follows the typical Unity development workflow:

```text
Create Scene
     ↓
Add GameObjects
     ↓
Add Components
     ↓
Write C# Scripts
     ↓
Configure Physics / Interaction
     ↓
Test in Unity Editor
     ↓
Build
```

This structure makes it possible to develop individual gameplay systems independently before integrating them into the complete game.
